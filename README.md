## 🚀 Project Overview

**E-Mart Management System** is a next-generation retail management solution built with Python and MySQL. Designed for seamless offline shopping experiences with enterprise-grade security and real-time inventory control.

## 📦 Core Features

### 🔐 Security Module
![2FA](https://img.shields.io/badge/Feature-2FA%20Authentication-important)


- **Dual-Factor Authentication** with TOTP support
- **Role-Based Access Control** (Admin, Manager, Cashier)
- **Encrypted Password stored**
- **Audit Logging** for all transactions
